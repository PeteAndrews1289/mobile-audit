# Security reporting

For a vulnerability in Mobile Audit itself, use [GitHub private vulnerability reporting](https://github.com/PeteAndrews1289/mobile-audit/security/advisories/new) so details can be reviewed before publication. Do not put exploit details, credentials, personal activity, or third-party app data in a public issue.

For a finding in another app, contact that app's owner through its disclosure program. This repository is not a disclosure channel for third-party targets. Evidence and example reports committed here should be synthetic or explicitly cleared for public release.
