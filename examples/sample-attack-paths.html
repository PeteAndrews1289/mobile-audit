App Transport Security disabled globally

Attacker control: A network path reached by the app, if cleartext traffic occurs

Possible attack path: If a reachable feature sends sensitive data over HTTP, someone able to observe or alter that network path could read or change the traffic. The report does not show that such a request occurs.
